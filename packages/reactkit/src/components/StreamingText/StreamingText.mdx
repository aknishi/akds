# StreamingText

> **Available from v1.6.0**

Reveals a block of text one character at a time, simulating an AI response streaming in. Pass the full, final `text` — the component handles the progressive reveal. Restart the animation for a new message by remounting with a new `key`.

## Usage

```tsx
import { StreamingText } from '@aknishi/akds-reactkit';
```
