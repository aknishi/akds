# Combobox

> **Available from v1.2.0**

A text input combined with a filterable dropdown list. The user can type to narrow options or click to open the full list. Supports single selection (returns a string) and multiple selection (returns `string[]`).

## Usage

```tsx
import { Combobox } from '@aknishi/akds-reactkit';
```
