# VisuallyHidden

> **Available from v1.7.0**

Hides content visually while keeping it in the accessibility tree, so screen readers still announce it. Use it to give controls an accessible name without visible text, or to add context to a visible label.

## Usage

```tsx
import { VisuallyHidden } from '@aknishi/akds-reactkit';
```
