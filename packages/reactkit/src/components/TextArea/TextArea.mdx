# TextArea

> **Available from v1.5.0**

A labelled multi-line text field with optional helper text and error state. By default the field grows to fit its content and can also be dragged taller via the native resize handle; set `resizable` to `false` for a fixed-height field that scrolls instead. The native `<textarea>` is forwarded a ref and accepts all standard HTML textarea attributes via `...rest`.

## Usage

```tsx
import { TextArea } from '@aknishi/akds-reactkit';
```
