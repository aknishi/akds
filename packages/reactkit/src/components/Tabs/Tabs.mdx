# Tabs

> **Available from v1.2.0**

Organises content into switchable panels. Composed of `Tabs` (context provider), `TabList` (the `role="tablist"` wrapper with keyboard navigation), `Tab` (individual trigger buttons), and `TabPanel` (content panels).

Supports both controlled and uncontrolled usage, disabled tabs, and full keyboard navigation (Arrow keys, Home, End).

## Usage

```tsx
import { Tabs, TabList, Tab, TabPanel } from '@aknishi/akds-reactkit';
```
