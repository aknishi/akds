# Basic Table

> **Available from v1.5.0**

A semantic HTML table for displaying tabular data, styled to match the design system's documentation tables. Compose with `Thead`, `Tbody`, `Tfoot`, `Tr`, `Th`, and `Td` subcomponents. `Th` supports optional column resizing — draggable and keyboard-operable — in both uncontrolled (`defaultWidth`) and controlled (`width` + `onWidthChange`) forms.

This is a lightweight, presentational table for static or simple tabular data. It does not include sorting, filtering, or pagination — those data-grid features are planned for a separate `Datagrid` package built on TanStack Table.

## Usage

```tsx
import { Table, Thead, Tbody, Tfoot, Tr, Th, Td } from '@aknishi/akds-reactkit';
```
