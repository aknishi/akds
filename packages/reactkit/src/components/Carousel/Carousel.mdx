# Carousel

> **Available from v1.2.0**

Displays a sequence of slides in a horizontal scrolling container. Accepts any React element as a slide — images, videos, cards, or other interactive content. Slides can auto-scroll with a configurable interval, pause on hover, loop seamlessly, and be navigated manually with overlay buttons or keyboard arrow keys.

## Usage

```tsx
import { Carousel } from '@aknishi/akds-reactkit';
```

With `loop` enabled the carousel wraps back to the first slide after the last, with no visible jump.

### Manual scroll

Set `autoScroll={false}` to disable auto-scrolling and rely entirely on the nav buttons and keyboard.

### Interactive content

Slides can contain any interactive content — buttons, inputs, links. The carousel pauses auto-scroll while any element inside it is hovered or focused.
