# useBreakpointUp and useBreakpointDown

> **Available from v1.7.0**

Return whether the viewport is at or above a breakpoint, or below it, and re-render when that changes. The widths come from the `--akds-breakpoint-*` tokens, so layout switches in JavaScript line up with the design system's breakpoints. Use them when the layout itself changes, for example a card list instead of a table on small screens.

## Usage

```tsx
import { useBreakpointUp } from '@aknishi/akds-reactkit';

function Orders() {
  const isWide = useBreakpointUp('md');
  return isWide ? <OrdersTable /> : <OrdersCards />;
}
```

## Where the boundary falls

A breakpoint is where its size starts: at exactly 768px the viewport is already `md`. So `useBreakpointUp` includes the breakpoint, and `useBreakpointDown` doesn't. At any width, exactly one of them is true.

## Server render

There is no viewport during a server render, so `useBreakpointUp` returns `false` and `useBreakpointDown` returns `true`. Both point to the small-screen layout, which the client corrects on hydration.

## Other media queries

For a width that isn't a breakpoint, or a query that isn't about width (orientation, color scheme), use [`useMediaQuery`](?path=/docs/reactkit-hooks-usemediaquery--docs).
